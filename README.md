# Romy Rose Jimmy — Freelance Portfolio

A responsive freelance developer portfolio built with React, Vite and Tailwind CSS.

## Included

- Responsive navigation
- Hero / personal positioning
- About section
- Freelance services
- Featured self-projects
- Professional employer projects
- Technology/skills section
- How I Work section
- Contact section
- GitHub / LinkedIn placeholders
- Mobile navigation
- Project filtering/show-all interaction
- Clean responsive UI

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Important: replace placeholders

Open `src/App.jsx` and replace:

- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN_USERNAME`
- `YOUR_EMAIL@example.com`

with your real details.

## Project links

FarmKonnect and RaiserBuddy are marked as self projects with GitHub buttons.

Ewire, Quik Pharma, EasyBin and saleStrait are marked as private employer projects and intentionally do not have public demo buttons.

## Deployment

The generated production files are in `dist/` after `npm run build`. This project can be deployed to common static hosting platforms such as Vercel, Netlify or GitHub Pages.
